# 레인보우 브레이커

벽돌 하나를 깨면 공 두 개가 더 쏟아지는 오리지널 캔버스 게임입니다. 외부 폰트, 이미지, 라이브러리, 분석 도구 없이 작동합니다.

## 실행

폴더에서 `python3 -m http.server 8080`을 실행하고 `http://localhost:8080`을 여세요. Node.js가 있다면 `npm start`도 됩니다. 파일을 직접 여는 `file://` 대신 HTTP 서버를 사용하세요.

## 조작

- **iPhone:** 플레이를 누르고 게임판 어디서든 좌우로 드래그하세요. 손가락을 패들 아래에 두어도 움직입니다. 화면 확대나 스크롤 없이 플레이합니다.
- **키보드:** 방향키로 이동, 스페이스/Enter로 시작 또는 일시정지, P/Escape로 일시정지 전환. Tab으로 버튼 이동, Enter로 실행합니다.
- 패들의 왼쪽이나 오른쪽 끝으로 받으면 공의 방향이 바뀝니다. 벽돌마다 공 두 개가 추가되고 최대 180개까지 유지됩니다.
- 마지막 공을 놓치면 기회 하나가 줄어듭니다. 기회는 세 번, 스테이지는 세 개입니다. 다음 스테이지에서도 점수와 기회가 유지됩니다.
- 소리는 처음에는 꺼져 있습니다. ‘소리 끔’을 눌러 켜세요. 다른 탭이나 앱으로 이동하면 자동으로 멈춥니다.
- 최고 기록은 현재 브라우저에만 저장됩니다. 저장이 차단되어도 게임은 작동합니다.

## 홈 화면 설치와 오프라인

iPhone Safari에서 HTTPS 주소로 한 번 열고 로딩이 끝난 뒤 **공유 → 홈 화면에 추가**를 선택하세요. 홈 화면에서 실행하면 독립 화면으로 열립니다. 첫 온라인 방문 후 게임 파일이 저장되면 오프라인에서도 실행됩니다. 서비스 워커는 HTTPS 또는 localhost에서만 작동합니다. Safari의 저장 공간 정리로 캐시가 지워지면 온라인으로 다시 열어 주세요.

GitHub Pages의 하위 경로에서도 실행되도록 모든 앱 경로는 상대 경로입니다. 업데이트 시 `sw.js`의 캐시 버전을 올리세요. 배포에는 HTML/CSS/JS, 매니페스트, 아이콘만 필요합니다. `node_modules`, `tests`, `proof`는 배포 대상이 아닙니다.

## 검증

`npm test`는 Node.js 기본 테스트 러너만 사용합니다. 물리, 고속 충돌, 패들 방향, 공 증식과 상한, 목숨, 스테이지, 초기화, 저장 차단을 검증합니다. `proof`에 실제 RED/GREEN 로그가 있습니다.

브라우저 검증: `npm install --no-save puppeteer-core` 후 로컬 서버를 실행하고 `CHROME_PATH="Chrome 실행 파일 경로" npm run smoke`를 실행하세요. `GAME_URL`로 테스트 주소를 바꿀 수 있습니다. 실제 Chromium에서 터치 입력, 키보드, UI 상태, 오프라인 재접속을 검증하고 모바일/데스크톱 스크린샷을 저장합니다. 런타임 의존성은 없습니다.

`window.game`은 개발자 도구에서 물리 상태와 메서드를 확인할 수 있는 테스트용 진입점입니다. 실제 iPhone Safari 하드웨어 테스트는 별도로 권장합니다. 캔버스 게임 특성상 화면 읽기 프로그램만으로 공의 위치를 판단하는 플레이는 지원하지 않으며 버튼, 조작 설명, 상태 알림은 접근 가능합니다.

코드, 아이콘과 그래픽은 이 게임을 위해 새로 제작했습니다. 기존 Flash 게임의 코드나 에셋을 사용하지 않았습니다.
