# 레인보우 브레이커

Particle Kuzushi의 **작은 픽셀을 깨고, 떨어진 조각을 받아 공을 늘리는 흐름**을 참고해 새로 구현한 캔버스 게임입니다. 원작의 코드·이미지·음악을 복사하지 않았으며 원작과 프레임 단위로 동일한 복제는 아닙니다. 외부 런타임 라이브러리·폰트·분석 도구가 없습니다.

## 게임 규칙

- 390×680 논리 게임판 위에 90열×65행, **5,850개**의 4×3 무지개 픽셀이 있습니다. 단계 이동 없이 한 판을 끝까지 지웁니다.
- 처음에는 반지름 1의 작은 공 하나만 천천히 출발합니다.
- 공이 픽셀을 깨면 그 자리에서 **조각 하나가 수직으로 떨어집니다.** 조각은 벽돌을 깨거나 다른 공을 만들지 않습니다.
- **패들로 조각을 받았을 때에만 새 공 하나**가 위로 출발합니다. 놓친 조각은 사라집니다. 자동 증식이나 즉시 두 공 생성은 없습니다.
- 기존 공은 벽·천장·픽셀에서 반사되며 패들로 계속 받아낼 수 있습니다. 패들 가장자리로 받으면 방향이 바뀝니다. 아래로 빠진 공은 사라집니다.
- 살아 있는 공과 아직 받을 수 있는 조각이 **모두 없을 때에만** 기회가 줄어듭니다. 기회는 3번입니다. 픽셀을 전부 지우면 승리합니다.
- 픽셀당 1점, 활성 공 상한 6,000개. 초반에는 개별 조각을 모으고, 누적된 공이 점점 큰 비를 만듭니다.

## 실행과 조작

`npm start` 또는 `python3 -m http.server 8080`을 실행한 뒤 `http://localhost:8080`을 여세요. `file://` 대신 HTTP를 사용합니다.

- **모바일 세로 화면:** 시작을 누른 다음 게임판 어디서든 좌우로 드래그합니다. 손가락을 패들 아래에 놓아도 됩니다.
- **데스크톱:** 방향키로 이동, 스페이스/Enter로 시작·일시정지, P/Escape로 일시정지 전환. 버튼은 Tab·Enter로 조작합니다.
- 소리는 기본으로 꺼져 있습니다. 다른 탭이나 앱으로 이동하면 자동으로 일시정지합니다.
- 다시 시작에는 확인 창이 있습니다. 최고 점수는 현재 브라우저에 저장되며 저장 차단 상태에서도 플레이할 수 있습니다.

## 홈 화면과 오프라인

iPhone Safari에서 HTTPS 주소로 온라인 접속한 뒤 **공유 → 홈 화면에 추가**를 선택하세요. 파일 캐시가 저장되면 오프라인으로 다시 열 수 있습니다. Safari가 저장 공간을 정리하면 온라인으로 재방문해야 합니다. 서비스 워커는 HTTPS 또는 localhost에서 작동합니다.

모든 앱 경로는 상대 경로여서 GitHub Pages 하위 경로도 지원합니다. 캐시는 `rainbow-breaker-v2-pixels`입니다. 이전 버전의 열린 화면은 새 워커 설치 후 **한 번 새로고침**하면 새 게임을 받습니다. 새 버전부터는 이후 워커 교체 시 이미 제어되는 클라이언트를 자동 새로고침합니다. 최초 설치에서는 게임을 끊지 않습니다.

## 검증

```sh
npm test
npm run soak
npm install --no-save puppeteer-core
npm start
npm run smoke
npm run test:update
```

- `npm test`: 밀집 배치, 실제 충돌 후 조각 낙하와 정확히 한 공 포획, 놓친 조각, 지연된 기회 소모, 상한, 빠른 공/얇은 픽셀, 좌우 접촉, 패들, 시간 간격, 그리드 경계, 승리·초기화·저장 차단을 확인합니다.
- `npm run soak`: 충돌 함수를 가짜 호출하지 않고 예상 착지점을 따라 패들을 움직이는 실제 물리 시뮬레이션입니다. 5초마다 공·조각·제거 픽셀 수, 전체 승리, 상한과 유한 좌표, 처리 시간을 `proof/organic-soak.json`에 기록합니다. 자동 패들은 사람보다 유리하므로 이 시간은 실제 사용자 클리어 시간 예측이 아닙니다.
- `npm run smoke`: 모바일 Chromium에서 CDP 실제 터치, 일시정지/재시작/소리, 유기적 공 누적, 고밀도 렌더링, 승리·종료 UI, 다양한 세로 화면, 키보드, 오프라인 재접속을 확인합니다. `GAME_URL`, `CHROME_PATH`로 주소와 Chrome 실행 경로를 지정할 수 있습니다.
- `npm run test:update`: 기존 배포 커밋 `106d68c`의 파일로 v1 워커를 실제 설치한 뒤, 같은 로컬 `/rainbow-breaker/` 경로에서 새 파일로 전환하여 v2 설치·구캐시 삭제·새 게임·오프라인 재접속을 확인합니다. 해당 커밋이 로컬 Git 이력에 있어야 합니다.

실행 결과와 스크린샷은 `proof/`에 저장합니다. Chromium 모바일 에뮬레이션은 **실물 iPhone Safari 성능이나 홈 화면 설치 검증을 대신하지 않습니다.** 헤드리스 브라우저의 rAF 간격은 호스트/컴포지터 제한 영향을 받으므로 물리 실행 시간과 전체 프레임 작업 시간을 별도로 기록합니다.

개발자 도구의 `window.game`으로 상태를 검사할 수 있습니다. 캔버스 특성상 화면 읽기 프로그램만으로 공 위치를 판단하는 플레이는 지원하지 않으며 버튼·설명·상태 알림은 접근할 수 있습니다.

배포에는 HTML/CSS/JS, 매니페스트, 아이콘만 포함하세요. `node_modules`, `tests`, `proof`, `.hallmark`, 로컬 로그는 공개 앱 배포 대상이 아닙니다.
